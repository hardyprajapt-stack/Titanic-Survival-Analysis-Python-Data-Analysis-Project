# 🧹 5️⃣ Data Cleaning

The project performs three main cleaning operations.

## Age Missing Values

Missing `Age` values are replaced with the median age:

```python
data['Age'] = data['Age'].fillna(data['Age'].median())
```

### Why Median?

The median represents the middle value after sorting the data and can be useful for filling missing numerical values.

---

## Embarked Missing Values

Missing `Embarked` values are replaced with the most frequently occurring value:

```python
data['Embarked'] = data['Embarked'].fillna(
    data['Embarked'].mode()[0]
)
```

`mode()[0]` selects the most common category.

---

## Cabin Column Removal

The `Cabin` column is removed:

```python
data.drop('Cabin', axis=1, inplace=True)
```

After this operation, the `Cabin` column is no longer present in the DataFrame.

---

# ✅ 6️⃣ Verify Data Cleaning

After cleaning, missing values are checked again:

```python

```

This helps verify the effect of the cleaning operations.

# 👶 1️⃣1️⃣ Age Group Analysis

The project creates age groups using:

```python
data['AgeGroup'] = pd.cut(
    data['Age'],
    bins=[0,12,18,35,60,100],
    labels=[
        'Child',
        'Teen',
        'Young Adult',
        'Adult',
        'Senior'
    ]
)
```

### Age Groups

| Age Range | Group       |
| --------- | ----------- |
| 0–12      | Child       |
| 12–18     | Teen        |
| 18–35     | Young Adult |
| 35–60     | Adult       |
| 60–100    | Senior      |

The project then compares survival across these groups:

```python
sns.countplot(
    x='AgeGroup',
    hue='Survived',
    data=data
)
```

### Project Insight

```text
Children had better survival chances.
```
